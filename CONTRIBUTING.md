# Contributing to Awesome Crypto Tax

Thanks for taking the time to contribute. Tax is high-stakes — accuracy matters more than volume here.

## Quick rules

- **Live tools only** (or beta, marked 🟡). Abandoned tools get marked 🔴 or removed.
- **One entry per row**, alphabetical-ish within sub-groupings where possible.
- **Match the column structure** of the section you're editing.
- **Use the legend**:
  - 🟢 Live · 🟡 Beta / Limited · 🔴 Inactive · ⚡ Top-tier · 🆕 Launched 2025/26 · 🎟️ Affiliate link · 🆓 Free / open-source
- **No referral spam.** Max one affiliate link per row. Mark 🎟️ only if you've verified the link works.
- **Country accuracy matters.** If you list a tool under "🇬🇧 UK", it must actually generate UK-compliant reports (HMRC SA, share-pooling, etc.). Wrong-country listings will be rejected.

## What we accept

- Crypto tax software (any jurisdiction)
- DeFi / NFT / Solana / EVM / specialty tax tools
- Enterprise / institutional crypto accounting platforms
- Free & open-source tax tools
- Tax-loss harvesting tools
- Portfolio trackers that meaningfully serve as tax-export sources
- Crypto tax APIs (for builders)
- MCPs / AI agents for tax workflows
- Block explorer CSV exports (free fallbacks)
- Crypto tax accountants / CPA firms with verifiable credentials
- Country tax-authority guidance pages (official only)
- Educational YouTube channels / blog series with consistent, factually-accurate content

## What we don't accept

- Anything that gives tax advice (only software / data tools / official authorities)
- Random "crypto tax" landing pages with no actual product
- Generic accounting tools without dedicated crypto support
- Affiliate-link spam (one link per row, max)
- Abandoned / unmaintained projects
- Anonymous "expert" Twitter accounts without verifiable credentials

## How to submit

1. Fork the repo
2. Create a feature branch (e.g. `feature/add-foo-tax-tool`)
3. Edit the relevant section
4. Open a PR with:
   - Tool / firm name + URL
   - One-line description
   - Country / region (if region-specific)
   - Why it belongs in the section you placed it in

## Affiliate links

If you're a tool owner and want to add an affiliate link to your row, that's fine — but please disclose in the PR description. Affiliate links must:

1. Lead directly to the project's referral page (no cloaked redirectors)
2. Replace, not duplicate, an existing entry
3. Be marked 🎟️

## Reporting issues

Found a broken link, dead project, or misleading information? Open an issue or PR with a quick note.

## Tax-law accuracy

Tax law changes. If you spot information in this README that's no longer accurate (e.g. a tax form retired, a country's rules changed), open an issue and link the official source. We don't try to be a tax-advice repository — we try to point at the right tools and authorities.
